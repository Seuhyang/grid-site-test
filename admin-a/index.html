관리자 (A안 · GitHub 토큰 직접 사용) ← 홈으로

1. 저장소 설정

깃허브 저장소 주소가 https://github.com/abcd/my-site 라면 Owner = abcd, Repo = my-site 입니다.

2. GitHub 토큰으로 로그인

GitHub → 오른쪽 위 프로필 → Settings → Developer settings → Fine-grained tokens → Generate new token 에서 발급하세요.
Repository access는 이 저장소 하나만 선택, Permissions → Contents를 Read and write로 설정해야 합니다.
토큰은 이 브라우저 탭을 닫으면 사라지고(세션 저장), 서버나 코드에 저장되지 않습니다.

접속자 통계

아래 상수에 GoatCounter 사이트 코드를 넣으면 이 버튼으로 총 방문자 수·오늘 방문자 수를 바로 볼 수 있어요. (무료, goatcounter.com에서 사이트 코드만 만들면 됩니다)

3. 새 그룹(사진 묶음) 만들기

글과 사진을 원하는 순서로 쌓아서 하나의 그룹(=하나의 페이지)을 만듭니다.


4. 기존 그룹 관리

메인 화면 순서

▲▼로 순서를 바꾸고 저장하면, 메인 화면에 그 순서대로 나옵니다. 순서를 안 정한 나머지는 최신순으로 자동으로 뒤에 붙어요.

회사 소개 페이지 문구

상단 메뉴의 '회사 소개'를 누르면 나오는 페이지의 글자를 여기서 고칠 수 있습니다. 저장하면 1분 내로 실제 사이트에 반영됩니다.
